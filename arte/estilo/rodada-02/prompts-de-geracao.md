## Base das primeiras tentativas

Use case: stylized-concept. Create a NEW original 3D modeling guide image. Reference estilo-a.png defines STYLE ONLY: chubby rounded toy shapes, matte vinyl/clay, warm saturated colors, soft corners, no outlines, upper-left sunlight and soft shadows. Reference captura-do-jogo.png defines content/design only. Extremely simple buildable low-piece-count primitives: rounded boxes, spheres, capsules, cylinders. No tiny texture, individual feathers/hairs/leaves, realism, haze, blur, text, numbers, arrows, labels, logos, watermark. Landscape EXACT 16:9 PNG at maximum native resolution available, ideally 3840x2160. Orthographic, no perspective.
